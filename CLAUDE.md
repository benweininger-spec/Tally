# Tally

Custom HOME/launcher app for Ben's Dasaita (HCT/MTC, QCM6125, Android 13) head unit
in his Toyota Tacoma: live OBD-II data, radio, one-tap Zlink, apps and widgets.

**Start with `docs/PLAN.md`.** It holds the decisions, milestones, acceptance checks,
rules for the builder (no vendor code or secrets in git), and the open questions.
The previous attempt (Expo/React Native, `tacomadash`) lands on branch `old-launcher`
once Ben pushes it; mine it per the table in PLAN.md §1, do not build on it.

`main` was cleared on 2026-10-20 for this project. The previous occupant, **Qamar**
(a self-contained Web Audio instrument in `index.html`), is archived intact on the
`qamar` branch with its full history and its own CLAUDE.md. Live artifact copy:
https://claude.ai/code/artifact/a97ffbad-e235-455d-a81c-f176cf1159d0. Do not touch
that branch unless Ben asks to work on Qamar.
